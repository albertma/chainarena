## 历史变更记录（原文档 v0.1–v0.3.3）

- **v0.4.0**：文档拆分为《产品设计》与《技术设计》两份文档（见上方映射表），原文归档。顺带修正 §8.5 AI 代打雇佣流程中的代币笔误（$GEM → $ARENA，与 §2.6 经济设计一致）。
- v0.3.3：**角色定位 + 流程规则更新**——① 新增 §2.2「游戏角色定位」：参与者角色总览（玩家 / Sensei / Second / Echo / 观众，人机各安其位）+ Fighter 五大流派（本命属性→锋刃/生息/流转/烈焰/磐岩：数值微调 + 必杀特效 + 被动，全部为回合内纯函数，数值走 game-config 可赛季调参）；② §2.3 对局规则澄清：明确三级胜利条件（KO 即胜 → 回合分先到 5 → 9 回合（回合分、剩余 HP）字典序判定/平局退款），定义回合分 = 当回合造成伤害更高者；出招参数化为 (move, element, salt)——STRIKE/HEAVY 属性从三系标签中选、SPECIAL 固定本命；③ 新增 §2.4「对局流程与状态机」：MatchCore 状态图、阶段窗口表、双超时/双 KO/平局/弃权/掉线重连等边界路径全集；④ 合约与测试同步：revealMove 增加 element 参数、RoundRevealed 事件带属性、新增 cancelMatch、仿真回归增加流派两两胜率与四类终局占比门；⑤ 修复 §3.1 架构图在旧版 mermaid 渲染器下的显示问题——节点与连线标签统一加引号（&/$/括号等特殊字符不再裸写）、拆分 `A & B --> C` 与 `<-->` 复合连线为独立语句、Sequencer 独立成节点承载 blob DA（不再连向子图 id），图示语义不变。
- v0.3.2：修正 §3.1 架构图——① 补上悬空的 ACT/OPS 节点连线；② 区分两条 AI 出招通道（Sensei 自有账户 vs Second 以玩家账户为 sender 的 operator key 签名）；③ Paymaster 策略签名方向改为 API↔SDK（链上只验签）；④ 补 resolveRound 任何人/后台触发流；⑤ 感知层改为索引器事件流推送（与 §10.1 一致）；⑥ 补 Sequencer blob DA 上 L1 的数据流。
- v0.3.1：**属性轮由三系（火/地/水）改为五行（金/木/水/火/土）**：克制环为 金>木>土>水>火>金（相克），相生对局为中性 ×1.0——10 种属性对恰好被"克 5 + 生 5"完全划分；Fighter 配置改为 VRF 五系选三（天然克制空档）；对局仿真与测试同步更新。
- v0.3：**更换游戏创意**。农场放置玩法被判定为"上链无意义"（去掉链游戏照样成立）。新概念「链斗 ChainArena」：全链异步格斗竞技场——每一招都是链上交易、裁决在公开合约、人与 AI 同场竞技。保留并强化 v0.2 已验证的技术骨架（ERC-4337 账户栈 / Paymaster 分档 / SessionKey+AgentOperator / 索引器 / Agent Runtime），游戏层与经济层全部重写。
- v0.2：AI Agent 子系统设计（沿用到 v0.3，角色重构为：AI 对手 / AI 代打 / AI 解说）。
- v0.1：初稿（ERC-4337 + L2 核心 MVP）。
