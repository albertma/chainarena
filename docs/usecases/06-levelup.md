# 用例 06：修炼升级（Level Up & Craft）

> 生命周期位置：对局之后的核心循环闭环 ｜ 参与者：玩家（可选：Second 代打期间自动进行）
> 前置条件：拥有 Fighter；XP 达标（升级）/ 持有 $ARENA（锻造）
> 成功保证：升级/锻造均为单笔链上交易，可批量并入赛后流程，无额外弹窗负担
> 上游依据：产品 §2.5 / §2.6；技术 §3.3（levelUp/craft）、§3.4（selector 白名单含 levelUp）

## 1. 触发与入口

| 触发 | 入口 | 动作 |
|---|---|---|
| 赛后 XP 达标 | 结算页「升级」按钮 / 赛后批量自动并入 | `levelUp(fighterId)` |
| 想要装备 | 大厅 →「锻造」 | `craft(gearId)` |
| 每日任务/首胜完成 | 任务页领取（发放 XP/$ARENA，链下签名资格 + 链上发放） | 任务系统（MVP 简版） |

**XP 来源**（产品 §2.6）：对局结算（endMatch 内含）> 每日首胜 > 任务。

**装备获取双通道**：锻造（本用例 ③，付费定向）与战后掉落（用例 07，免费随机，endMatch 批内被动铸发），共享同一装备池与数值表。

## 2. 主流程（成功路径）

### ① 升级（最常见：赛后批量）

```
endMatch 后客户端检测: XP ≥ 升级阈值
→ 并入赛后批量单（会话密钥可签，levelUp 在 selector 白名单内）:
   executeBatch[ levelUp(fighter), createMatch(...) ]
→ 无独立弹窗、无独立等待——升级动画在下局匹配期间播放
```

### ② Lv.5：必杀解锁（战力质变节点）

```
levelUp 使等级 = 5 → SPECIAL 可用
→ 卡面解锁必杀特效展示（如 锋刃「破甲斩」: 对 GUARD 无视减伤，全额 80 伤害）
→ 这是本游戏唯一的"技能解锁"节点——刻意极简，构筑差异靠流派与装备（产品 §2.2.2）
```

### ③ 锻造装备（W10+）

```
大厅 →「锻造」→ 选择 gearId（MVP 仅 6 件套固定属性）
→ 一笔 UserOp（passkey 签名，craft 不在会话密钥白名单 → L2）
→ craft(gearId): 扣 $ARENA（部分销毁 = sink）→ 铸 ERC-1155
→ 装备数值全部在 game-config（configHash 锚定），客户端本地校验后展示
```

## 3. 状态与数据变化

| 对象 | 之前 | 之后 |
|---|---|---|
| Fighter 等级/XP | Lv.L / X | Lv.L+1（或 Lv.5 解锁必杀） |
| 装备（W10+） | 无 | ERC-1155 ×1（固定属性 6 选 1） |
| $ARENA | — | − 锻造费（其中固定比例销毁） |
| 签名 | — | levelUp = L1 会话密钥；craft = L2 passkey |

## 4. 体验要点

- 弹窗：升级 **0**（会话密钥自动签）；锻造 1 次 passkey
- 节奏：升级藏在赛后批量里"无感发生"；锻造是主动操作，~$0.005 Gas（Token 代付）
- 反馈：升级/解锁动画复用等待窗口（下局匹配中），不占玩家时间

## 5. 异常与边界

| 情形 | 处理 |
|---|---|
| XP 不足点了升级 | 客户端预检拦截；即便绕过，bundler 模拟 revert → 丢弃（技术 §6.2 护栏原则同样适用于客户端预检） |
| 赛后批量中 levelUp 失败 | 批内 revert 则整笔原子失败 → 客户端拆分为 [createMatch] 单独重发（优先保再排） |
| 代打期间的升级 | Second 的 selector 白名单含 levelUp → 代打期可自动升级（合规：非资产转移类操作） |
| 装备与流派叠加失衡 | 数值回归门（±3%，技术 §10 仿真器）+ configHash 赛季调参，不动合约 |
| Fighter 卖出后 XP | XP/等级随 NFT 走（挂在 Fighter 上）；段位不随（挂账户）——与用例 04 一致 |

## 6. 权限与安全

- levelUp：L1 会话密钥可签——**无资产转移语义**，密钥泄露也不能借此偷钱
- craft：L2 passkey——涉及 $ARENA 消耗，与会话密钥隔离
- 锻造费销毁比例、装备数值均为 configHash 参数：调平衡不动合约、链上可验证

## 7. 规格待定项

1. XP 曲线与等级上限（MVP 建议上限 Lv.9：对应 BO9 叙事，Lv.5 必杀为唯一质变点）
2. 装备"佩戴/生效"机制（MVP 6 件套是否即得即生效，W10+ 再引入槽位）
3. 代打对局的 XP 是否随收益一起打 7 折（当前仅明确奖金打折，产品 §4.3）
4. 任务系统的资格签名防刷细节（技术 §8.2 已留端点）
